# Guardrails evaluation corpus

All data is synthetic.

- `pii/texts.jsonl` (190 samples) and `pii/claims_table.json` (40 rows) are generated by
  `scripts/generate_guardrails_corpus.py` with Faker (fixed seed). Gold labels are exact
  character spans recorded when each value was inserted. Values are valid-format:
  Faker SSNs avoid invalid areas, card numbers and NPIs pass their check digits.
- `injection/attacks.jsonl` (35) and `injection/benign.jsonl` (35) are hand-written. Benign
  inputs deliberately resemble attacks ("ignore the previous total", "developer mode" in
  a product guide). `context` is `chat` (a user message) or `untrusted` (content fenced
  with `wrap_untrusted`, e.g. a document or CSV cell).

The corpus was written and committed **before** the detectors were scored against it,
and is not edited to make targets pass. Results: `docs/guardrails-results.md`, produced
by `scripts/guardrails_report.py`.
