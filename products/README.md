# products

The four AI products in this portfolio. Each product is an independent service
built on top of the shared `platform/`. All data used by products is synthetic.

| Folder | Product |
|---|---|
| `claims-onboarding/` | Claims Onboarding |
| `query-desk/` | Query Desk |
| `rewards-advisor/` | Rewards Advisor |
| `meal-vision/` | Meal Vision |

Folder names use hyphens; Python packages inside use underscores
(e.g. `claims_onboarding`).
